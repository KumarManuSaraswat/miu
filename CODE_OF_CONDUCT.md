# Code of conduct

Miu welcomes people with different backgrounds and levels of experience. This policy applies to the project's issues, pull requests, discussions, and other spaces managed by its maintainer.

## Working together

- Discuss the work with patience and specific, useful feedback. Critique an idea or change without attacking its author.
- Respect people's names, boundaries, and privacy. Ask before sharing someone else's messages, recordings, or personal details.
- Allow room for questions, mistakes, and disagreement. Accept a maintainer's scope decision without repeatedly pressuring contributors.
- Do not harass, threaten, discriminate, impersonate, publish private information, or post sexual content, spam, or repeated personal attacks.

## Reporting and response

Use GitHub's **Report content** or **Report abuse** controls for harmful public content. Where GitHub offers **Report to repository admins**, it reaches the repository's maintainer; reporting to GitHub Support is also available. See [GitHub's reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). If a concern involves the maintainer, use GitHub Support rather than a public argument. Do not post private evidence in an issue. Security vulnerabilities have a separate process in [SECURITY.md](SECURITY.md).

The repository owner is the initial moderator. Depending on the conduct and context, they may request a correction, hide or remove content, close or lock a conversation, or restrict participation. Serious threats or disclosure of private information may require immediate action. Decisions should be proportionate and explain the rule involved where doing so does not expose private information. Reconsideration can be requested through the same available reporting channel with relevant new context.

Miu has no independent moderation team or guaranteed response time. Project moderation does not replace GitHub's own rules or reporting process. These rules apply to the maintainer as well as contributors.
